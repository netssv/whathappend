# Command Reference

The WhatHappened terminal features an extensive suite of commands (+50) spanning DNS checks, web infrastructure triage, OSINT, and environment emulation.

To improve readability and search context, our command reference has been split into focused modules. Please select a category below:

- [🌐 Network & DNS](docs/cmds/network.md): `dig`, `map`, `isup`, `nslookup`...
- [🕸 Web & Infrastructure](docs/cmds/web.md): `curl`, `openssl`, `stack`, `cms`...
- [🕵️ RECON & Security](docs/cmds/recon.md): `email`, `sec`, `malware`, `seo`...
- [📱 Emulation & Testing](docs/cmds/emulation.md): `useragent`, `mobile`, `geo`...
- [💻 System Utilities](docs/cmds/system.md): `tabs`, `config`, `nav`, `flush`...
